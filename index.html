Extracteur de bilans biologiques

Colle un copier-coller de compte-rendu de biologie standardisé : l'outil extrait chaque examen avec ses valeurs successives, construit un tableau examen × date, et permet d'insérer les valeurs dans un modèle de résumé de type courrier. Tout se passe dans le navigateur, rien n'est envoyé où que ce soit.

1. Coller le compte-rendu

Ordre d'affichage personnalisé (tableau, liste, CSV)

Une ligne par bloc, dans l'ordre voulu : Titre : terme, terme, …. Un terme est un morceau du nom de l'examen (sodium), un nom exact (= Protéines), un nom restreint à une rubrique ou une unité (sodium @ sanguins), une rubrique entière du laboratoire (rubrique=HEMATOLOGIE) ou * pour tout le reste. Les examens non reconnus vont à la fin, dans « Autres ». # commence un commentaire. Sans texte : ordre du laboratoire.

Une ligne par examen. Une date : valeur à la date choisie, ou la plus proche antérieure. Comparer : première valeur de l'intervalle (entrée) → dernière valeur (sortie). Les dates sont indiquées une fois dans le titre du bloc (prélèvement majoritaire) ; une valeur prélevée à un autre moment porte sa propre date entre crochets.

Modèle de résumé

Écris ton modèle librement, avec tes propres phrases d'interprétation. Insère une valeur avec {{Nom exact de l'examen}} (valeur + unité), {{Nom|valeur}} (valeur seule) ou {{Nom|date}} (date du prélèvement utilisé). Si le même nom existe sous plusieurs rubriques ou plusieurs unités, précise avec {{Nom @ Rubrique}} ou {{Nom @ unité}}. Clique un examen dans la liste à droite pour insérer son nom exact.
